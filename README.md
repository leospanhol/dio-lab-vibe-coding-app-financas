# 💸 App de Organização de Finanças Pessoais com Vibe Coding de desafio do DIO realizado por Leonardo.

PRD do copilot

PRD - Aplicativo de Organização de Finanças Pessoais

Contexto:
Criar um aplicativo que ajude pessoas a organizar suas finanças de forma simples,
usando conversas naturais em vez de formulários ou planilhas.

Problema:
Muitos desistem de controlar gastos porque os apps atuais exigem muita entrada manual
e pouca personalização. A proposta é oferecer uma experiência leve, conversacional
e com dicas automáticas de economia.

Público-Alvo:
Iniciantes que querem praticidade e clareza no controle financeiro.

Funcionalidades-Chave:
1. Registrar gastos via chat em linguagem natural.
2. Classificar automaticamente as transações.
3. Definir e acompanhar metas financeiras.
4. Receber recomendações do "Agente Financeiro".
5. Visualizar relatórios simples e personalizados.

MVP - Entregável:
- Telas principais: Chat Financeiro, Metas, Relatórios, Configurações.
- Recursos necessários: NLP (interpretação de linguagem natural),
  motor de classificação, banco de dados simples, segurança de dados,
  interface acessível.
- Validação inicial: Teste com 10–20 usuários, medindo retenção,
  número de registros e feedback qualitativo.

Conceitos Didáticos:

PRD (Product Requirements Document):
Documento que organiza e explica o que será construído em um produto.
Estrutura básica:
- Contexto: por que o produto existe
- Problema: o que precisa resolver
- Público-alvo: quem vai usar
- Funcionalidades: o que deve ter
- MVP: o que será entregue primeiro
O PRD funciona como um mapa que guia o desenvolvimento.

Vibe Coding:
Forma de criar protótipos e testar ideias de software de maneira intuitiva e criativa,
sem depender de código tradicional.
Objetivo: validar rapidamente a experiência do usuário e a "vibe" da interação.
Características:
- Usa ferramentas visuais ou conversacionais (como Lovable).
- Permite simular fluxos de interação sem programação pesada.
- Ideal para iniciantes, pois prioriza lógica e criatividade.
Vibe Coding funciona como um rascunho interativo: você desenha a conversa
e já sente se a ideia funciona.

Síntese:
- PRD = documento que organiza a ideia.
- Vibe Coding = método criativo para transformar essa ideia em protótipos rápidos.
- Lovable = ferramenta que permite testar esses protótipos sem precisar programar pesado.

Vibe Coding é sobre clareza, curiosidade e criatividade, não sobre perfeição técnica. Cada interação é um experimento, quanto mais clara for sua intenção, mais surpreendente será o resultado.
